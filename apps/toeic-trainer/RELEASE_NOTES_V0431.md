# TOEIC Trainer V0.4.3.1｜手機版面修整

## 本版修正

- 首頁改成簡短的「今天練哪一項？」與閱讀／單字／文法三個直接入口，四項學習統計縮小；其他入口和題庫審查移往可收合區塊。
- 閱讀文章改成連續的英文段落，不再每一句各占大型卡片；交卷後依舊能逐句展開中文翻譯與句型解析。
- 閱讀答題時不重新渲染整篇文章，只更新選取狀態、已答題數及交卷按鈕，降低捲動跳動風險。
- 閱讀難度說明、日常自選題組與完整 100 題模考設定改成可收合；原有開始按鈕和設定欄位 ID 保留。
- 單字測驗入口優先顯示；「搜尋／收藏單字」可收合，字庫每頁最多 8 張，支援英文／中文搜尋、來源篩選及上下頁操作。
- 未交卷試卷提醒改成緊湊資訊列；保留「繼續作答」與「放棄草稿」。
- 字體、卡片間距、手機滿版、安全區及深色模式進行局部修整。

## 資料與題庫保護

- 完全沒有修改任何 `data/*.js` 題庫檔案或已通過測驗的題目 ID。
- 閱讀、單字與文法仍維持「整份交卷後顯示答案與解析」；100 題／75 分鐘模考、暫存及重練規則不變。
- Core 的儲存鍵 `toeic-trainer-v01:learning-state`、備份鍵與 Schema 1 均保持不變。
- Goal Manager 資料與程式沒有任何更動或自動寫入。
- 640 題機械結構查核結論不變；188 題優先語意覆核仍待獨立品質審查，不等於 188 題已證實錯誤。

## 驗收

- 7 組 Node.js 回歸測試。
- 320、360、390、768px 操作、暗色模式、無橫向捲動、閱讀作答／提交、單字瀏覽與分頁、文法暫存／續答、舊 Session 保留與 100 題模考題號導航。
- 使用者 Android 手機實機驗收仍須完成。
