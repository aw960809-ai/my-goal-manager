# TOEIC Trainer V0.4.3｜介面重整與題庫機械審查

## 修改範圍

以已通過 Android 手機驗收的 V0.4.2 為基礎，只新增非破壞性的介面與品質報告功能：

- 手機首頁：縮小說明 Hero、直接進入閱讀／單字／文法、四項統計簡明排列；題庫品質與雙系統分工收進可展開區塊。
- 閱讀：選篇與正式測驗設定更好辨識；長篇英文提高行距與選項間距；測驗時收起非必要設定，不再讓浮動交卷列蓋住長文。
- 文法／閱讀逐題試卷：題數進度、可展開的題號總覽、跳題、上一題／下一題，以及手機交卷操作區。
- 交卷後集中檢討：提供「全部題目／只看錯題」切換；作答中無此功能，答案依舊直到交卷才揭曉。
- 紀錄與資料核對：原有紀錄不變；只讀核對改為按需展開（不刪除功能）。
- 6 欄手機導覽，320、360、390、768px 適配，亮／暗色跟隨系統。

## 題庫審查的實際範圍

本版沒有增加題數。全部 640 道書面題、800 張字卡、43 篇文章、20 個文法主題及既有 ID **原樣保留**。

`js/quality-v043.js` 對 640 題執行可重現的結構審查：ID、題文與篇章指紋、選項文字（保留撇號對語法的區別）、答案索引、必要英文／中文解析、Part 6–7 篇章完整性。資料來源報告為 `BANK_AUDIT_V043.json`。

- 640 題結構檢查通過；0 題發現已證實的機械性封鎖缺陷。
- 188 題被標記為需要優先人工語意覆核（類別重疊），包括：158 題欠缺可機器比對的證據欄、56 題疑似干擾項太明顯、43 題解析偏短。
- **這不代表 640 題答案已獲專業驗證，也不代表標記題必然錯誤。** 不能單靠語句比對認定唯一正解；舊題不會被暗中改寫或隨意封存，避免破壞既有錯題與歷程對應。
- 經確定的結構缺陷會使題庫啟動檢查停止（不是靜默收錄）；如果後續確認有語意錯誤，須先建立明確的審核結論及新題版本，再隔離錯誤題，不覆寫舊 Session 使用的 ID。

## 資料安全與相容性

- 保持 `Core.SCHEMA=1`、`toeic-trainer-v01:learning-state`、`toeic-trainer-v01:learning-state-backup` 與舊草稿鍵不變。
- `data/content.js`、`data/advanced.js`、`data/v04_bank.js`、`data/v041_progression.js`、`data/v042_official.js` 沒有改動。
- Goal Manager **仍完全獨立**；本版不自動同步、不讀寫 Goal Manager 本機資料。僅保留 V0.3 的唯讀核對。
- 完整模考保留 100 題、75 分鐘、30／16／54 配置；結果非 ETS 官方分數。

## 驗收
