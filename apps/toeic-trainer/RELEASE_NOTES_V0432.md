# TOEIC Trainer V0.4.3.2 — 快捷篩選與主題列表

## 操作介面

- 閱讀：全部／基礎／中階／高階／既有五個快捷鍵；輸入名稱即可搜尋 43 篇文章，七篇一批顯示，點文章直接進入正式測驗。
- 文法：推薦、動詞、詞性、子句、進階、全部六個分類按鍵，20 個現有主題依分類以精簡列呈現；搜尋涵蓋所有主題，點一列直接開考。
- 單字：全部／待複習／收藏三個快捷篩選，商務場景分類收在單一展開區；保留英文與中文搜尋及每頁八張字卡。
- 題數與日常題型設定：採單鍵分段式選項，原始 select ID 留作唯一狀態來源，不重寫任何組題或結算引擎。
- 進行測驗時只顯示題目及作答區，交卷後才顯示正確答案與解析，暫存與 100 題閱讀模考繼續使用原來的正式測驗流程。

## 不變的安全邊界

- 640 道書面題、800 張字卡、43 篇閱讀、20 個文法主題的來源檔案位元相同，原 ID 不變。
- `toeic-trainer-v01:learning-state`、Schema 1、Session、錯題、間隔複習、未交卷草稿都保持原本結構。
- Goal Manager 完全沒有更新，也沒有連動寫入。
- 188 題仍是「優先專業語意覆核」候選，機械查重通過不等同於完整英文答案認證。

## 驗收

- 8 組 Node.js 回歸測試；隔離瀏覽器對 320、360、390、768px 完成閱讀搜尋與交卷、文法分類與暫存／恢復、單字篩選與出題。
- 安裝器支援來源 V0.4.3 和 V0.4.3.1；只有完整雜湊驗證通過才會更新，並先備份程式檔。
- 請使用手機原本的 Chrome 與 `127.0.0.1:8766`，不要清除網站資料。
