# TOEIC Trainer V0.4.3.3｜設定中心 × 外觀配色

## 本次改動
- 統一 6 個主導覽入口：總覽、閱讀、單字、文法、分析、設定。
- 錯題、歷史紀錄歸入「分析」，使用兩個快捷按鍵；原來 `tab('history')` 等舊跳轉繼續受支援。
- 設定集中外觀、單字查詢、訓練端備份、Goal Manager 只讀比對、來源和題庫品質；備份和 Goal Manager 使用說明預設收合。
- 預設主色由綠色改為霧藍灰。可切換靛紫、石墨、青綠，或使用系統／淺色／深色顯示模式；另設標準／大字。
- 外觀偏好為新的獨立 `toeic-trainer:ui-preferences-v1` 鍵，絕不修改學習 Session 或 Goal Manager 資料。

## 原封不動的部分
- 640 道書面題，800 張字卡，43 篇文章，20 個文法主題及原有 ID。
- Schema 1、舊 Session、錯題、SRS、草稿、交卷後集中批改、100 題／75 分鐘模考、唯讀目標核對演算法。
- 188 題為待優先語意覆核項目；不是 188 題已證實錯誤。

## 測試與限制
- `npm test` 九組 Node.js 測試與 320／360／390／768px 實際 Chromium 模擬交互測試通過。
- Theme 保存／重新開啟、備份下載、字庫查詢、分析分頁、閱讀交卷及模考啟動均測試通過。
- **手機實機驗收仍需使用者確認**，本版不建置 Goal Manager 自動連動。
