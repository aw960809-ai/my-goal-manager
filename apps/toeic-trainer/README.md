# TOEIC Trainer V0.4.3｜手機版面重整與題庫品質初審

獨立的非官方 TOEIC 閱讀、單字與文法訓練工具。所有測驗均是「完整交卷後才批改、顯示答案與解析」。目前不含聽力，也不與 Goal Manager 自動同步。

## 使用方式

在 Termux 執行：

```bash
cd ~/toeic-trainer-v0.1
python -m http.server 8766 --bind 127.0.0.1
```

使用**原本的 Chrome** 開啟：`http://127.0.0.1:8766/?v=v0.4.3-ui-audit-20261012`

第一次升級以前，請先到「紀錄」下載完整訓練備份；不要清除網站資料或更換本機連接埠。Chrome 的歷史資料不存放於此 ZIP。

## V0.4.3 改進

新增 `css/layout-v043.css` 與 `js/quality-v043.js`：首頁精簡、六分頁貼合手機、閱讀長文可讀性、考試專注顯示、題號總覽、提交後只看錯題、紀錄低頻核對收合。程式內容由 `js/app.js` 延用已驗收 V0.4.2 的核心資料及考試流程。

題庫規模固定：800 個字卡詞條；640 題（Part 5：368、Part 6：44、Part 7：228）；43 篇文章；20 個文法主題。

題庫報告 `BANK_AUDIT_V043.json`：640 題機械結構通過、0 個結構封鎖、188 題優先人工語意覆核。**並不表示全部題目已完成專業答案與語意審查。** 每一道原有題號與全文不改寫，也不得透過改寫舊題灌數。

## V0.4.3.1 手機操作介面
- 首頁上方直接開啟閱讀／單字／文法訓練；其他功能入口預設收合。
- 閱讀原文使用連續段落顯示；作答時不公布答案，交卷後可逐句展開解析。
- 單字查閱列表預設收合；展開後可搜尋／分類／每頁 8 張分頁收藏。
- 原本的「正式交卷」「暫存離開」「題號總覽」「100 題模考」與紀錄還原功能不變。
- 本次只修改訓練程式 UI，沒有新增題目或啟用 Goal Manager 自動同步。

## V0.4.3.3｜設定中心與霧藍灰配色

- 主導覽固定六項：總覽、閱讀、單字、文法、分析、設定。分析內以「錯題與弱點／學習紀錄」兩個直接按鍵切換，交卷後的舊紀錄入口仍可正常開啟。
- 設定集中顯示模式（跟隨系統／淺色／深色）、主題色（霧藍灰／靛紫／石墨／青綠）、文字大小，並集中單字庫查閱與收藏、備份還原、Goal Manager 唯讀核對、題庫機械審查資訊。
- 外觀偏好存於 `toeic-trainer:ui-preferences-v1`，與 `toeic-trainer-v01:learning-state` 完全分離。偏好無法永久儲存時會提示，不會破壞舊資料。
- 新增 `css/preferences-v0433.css` 與 `js/preferences.js`；原本 640 題、800 張卡、43 篇文章、20 文法主題，以及交卷批改／75 分鐘模考的計算來源皆未修改。仍保留 188 題優先語意覆核警示。
- Termux 仍使用 `127.0.0.1:8766`；升級後的開啟網址：`http://127.0.0.1:8766/?v=v0.4.3.3-settings-theme-20261012`。
- 安裝前到「設定 → 資料與備份」或舊版「紀錄」頁匯出完整訓練備份。不要清除網站資料或更換連接埠。

## V0.4.3.4｜單字庫從設定移回學習頁

- 「單字」頁提供兩個直接入口：「記憶測驗」與「單字庫／收藏」。字庫保留搜尋、全部／到期／收藏、商務情境、每頁 8 張分頁、收藏切換。
