# 個人目標與學習行動管理系統 V98.11.5

## 本版定位
V96.5 是「七模組 UI 一致性＋運行穩定性」修正版。優先原則：**程式可運行、版面配置正常、手機優先、模組不互相污染、資料與規則可獨立調整**。

## V96.3.9｜可逆操作
- 「安排執行」可取消；取消採狀態保留，不刪除安排歷史。
- 活動雷達加入行事曆後可「取消加入」；只撤銷個人行事曆安排，不刪除活動雷達資料。
- 手動行事曆活動仍可刪除；學校固定行事維持唯讀。
- 計時完成仍寫入同一套 `db.logs`，分析直接讀取實際投入紀錄，取消安排不會影響既有紀錄。

## V96.3.9｜計畫 × 實際統計口徑統一
- 「計畫實際執行率」只表示該安排是否已產生實際投入，不等同於完成率。
- 「時間達成率」＝同一 `planId` 的累計實際分鐘 ÷ 計畫分鐘；計時進行中會即時計入。
- 「已達計畫」以累計實際分鐘達到計畫分鐘為準，不以第一次按下完成作為唯一完成條件。
- 同一提前安排可多次計時，實際分鐘會持續累計至同一 `planId`。
- 「逾期未達計畫」排除已取消安排；部分完成但未達計畫者在到期後仍會列入。
- 「估時吻合度」改以每一個已配對計畫的累計實際時數與計畫時數計算，避免多次計時被錯誤拆算。
- 總覽的「本週計畫投入」與分析的「本週計畫」採同一份 `executionPlans` 資料來源；「本週實際投入」則統計本週實際紀錄。

## 開發方式
- `index.html`：正式網站入口
- `preview.html`：單檔手機預覽，不依賴鄰近 CSS/JS/JSON
- `css/`：視覺樣式
- `js/`：模組程式
- `config/`：可調規則
- `data/`：公開目錄資料
- 個人資料仍留在瀏覽器 localStorage / IndexedDB，不放 GitHub。

## 七模組
總覽、目標、執行、活動、獎學金、行事曆、分析。活動雷達與獎學金維持獨立資料、邏輯與 UI。

## 預覽
直接開 `preview.html`。正式 GitHub Pages 則使用 `index.html`，由相對路徑載入模組。


## V96.5 測試收尾與正式環境隔離
- 正式 GitHub Pages 版本不再渲染進階壓力測試工具入口。
- 進階測試工具程式碼移至 `js/devtools.js`，僅在 standalone preview / development build 注入。
- production 執行環境即使載入測試函式，也會拒絕開啟開發者測試入口。
- 壓力測試維持非破壞性：只操作記憶體複本。
- 測試完成後不會把測試資料寫入正式資料庫。
- Preview 保留完整壓力測試面板，供開發驗收使用。

## V96.5 手機版留白修正
- 移除短頁面的 `100vh` 最小高度，避免內容結束後產生大面積空白。
- 固定底部導覽僅保留實際需要的安全間距。
- 保留 Android Safe Area 與底部導覽遮擋防護。

## V97.11.0｜重構安全底座
- `config/version.js` 為頁面、AppConfig、PWA、Service Worker 的唯一執行版本來源。
- Study Log 統一區分 `goal-study`、`other-study`、`system`；舊資料由 normalize 相容轉換。
- 系統完成事件不再被視為實際讀書紀錄。
- 計時器狀態可跨 PWA／Android 背景終止恢復。
- localStorage 永久寫入失敗時不再誤報保存成功。
- AutoFetch／TOEIC 只更新資料；自動 push 後以 `workflow_dispatch` 明確呼叫 `pages.yml`，GitHub Pages 僅由 `pages.yml` 部署。
- 自動寫入 main 的工作共用 concurrency，push 前先 rebase。


## V97.12.0｜Design System 收斂
- 正式視覺改為「暖霧灰 × 霧藍灰 × 灰莓果 × 石墨文字」。

## V97.13.0｜首頁、執行與五項主導覽
- 底部主導覽由 7 項收斂為：首頁、目標、執行、行事、分析。
- 活動雷達與獎學金保留完整功能，改由首頁「探索機會」進入。

## V97.14.0｜目標雙模式與 Goal Domain
- 目標頁預設改為逐層瀏覽：方向 → 階段目標 → 子任務 → 具體行動。
- Breadcrumb、上一層、搜尋與新增下層皆保留在單手手機操作範圍內。
- 完整目標地圖保留，搜尋／狀態／層級篩選與整棵樹鳥瞰不刪除。
- 新增 `js/domain/goals.js`，先抽出純階層與期間邏輯：getTask、children、roots、ancestors、periodForTask、browseItems。
- `app.js` 保留相容 wrapper，既有呼叫點不需一次重寫。
- 新增 `tests/goal-domain.test.js`，GitHub Pages 部署前會執行 GoalDomain 單元測試。

## V98.11.5｜資料安全及發布修復
- 修正 AutoFetch 未納入來源覆蓋檔導致 rebase 失敗。
- Pages 打包所有必要的 PWA 圖示與資源，組裝後檢查是否存在。
- 已有資料無法解碼時進入唯讀保護，不以空白 seed 直接覆蓋。
- 清除快取只影響原版目標系統，不連帶移除同網域其他 PWA。
- 目標與 TOEIC 計畫不在一般啟動時重設使用者自訂項目。
- 計時、補登、修改、行事及外觀設定在寫入失敗時不回報成功，並盡可能回復操作前狀態。
- 本版改動不會變更資料 schema；個人資料仍須依設定頁完整備份。
