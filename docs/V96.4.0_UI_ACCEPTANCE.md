# V96.4.0 UI refinement baseline 測試收尾與正式環境隔離

## 目的
完成 V96.3 壓力測試後，將開發測試工具與正式 GitHub Pages 工作層分離，並固定本版驗收基準。

## 驗收結果
- 七大工作模組：PASS
- 設定控制層：PASS
- 資料驗證／Checksum：PASS
- 非破壞性生命週期壓力測試：PASS
- 匯出／匯入往返：PASS
- 損壞備份攔截：PASS
- 原始正式資料不被壓力測試修改：PASS
- Preview 可載入 `js/devtools.js`：PASS
- Production `index.html` 不載入 `js/devtools.js`：PASS
- Production 不渲染進階測試工具 Modal：PASS
- Production developer API 入口不存在：PASS
- Service Worker cache：V96.4.0 UI refinement baseline
- JS syntax：PASS
- Static QA：PASS

## 正式環境原則
`js/devtools.js` 只屬於 standalone preview / development build；GitHub Pages production workflow 不複製該檔案，也不建立 developer modal。

壓力測試只操作記憶體複本，不透過 `save()` 寫入正式資料。

## 進入下一版前禁止事項
除非修正阻斷性 Bug，不再變更 V96.3 核心資料生命週期邏輯。下一階段可進入 V96.4 UI/UX 最終精修。
