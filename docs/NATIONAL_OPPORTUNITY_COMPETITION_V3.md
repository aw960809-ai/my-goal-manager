# Goal Manager：全國活動精準蒐集 V3（2026-10-16）

此次修正回應「全國來源 8/8 健康，但 131 筆官方清單中沒有實際收錄」的問題。

## 蒐集與審查規則

- 全國競賽：可以**線上初賽投稿／繳交作品**，而決賽須前往其他縣市時，仍可推薦；在卡片醒目顯示「決賽需到場」及**已核實**的縣市。如果官方未列地點，顯示「地點依官方公告」，不臆測。若初賽、作品繳件或資格審查本身必須到場，仍排除。
- 只有「網路報名」而沒有線上提交參賽作品的證據，**不等於**可遠距參賽。未證實不收錄。兒童活動、特定身分、前置資格、已截止案件仍不收錄。
- 一般法律講座、研習不因「線上報名」而被視為線上參加；未能確認線上參與的遠地講座仍不推薦。東海與台中來源及停用彰化／南投、臺政專屬講座的設定保持不變。
- 以前青年第一讚**清單沒有標示截止日就被直接排除**；現在允許進入**官方詳情頁**核對，只有詳情明確顯示有效截止日，才能收錄。
- 修正日期解析錯誤：遇到「申請期間」只有**開始日**卻沒有截止日，不把開始日誤認成截止日。

## 診斷與安全

- 同時記錄**來源連線健康**與**內容收錄結果**。每個來源逐項統計「主題不符、期限未明、初賽須到場、沒有線上投稿證據、資格限制」等原因，官方範例連結最多每類2筆（只含公開標題與官方連結，不含個資）。
- 設定頁僅簡要呈現前三項最常見排除原因；完整彙總在 `data/activities.json` 的 `meta.nationalExpansionReviewBySource` 中。
- 官方來源任何失敗維持既有 fail-closed 與舊資料保護機制，不因修正而繞過網站限制或虛構活動。
- **本修正僅修改程式碼及測試**，不動既有 Goal Manager 目標、學習紀錄、TOEIC、獎學金或個人行事曆，也不直接修改正式活動資料。

## 部署驗收

先在獨立 GitHub PR 執行全套測試；合併後才重新執行 `autofetch.yml`，核對 `NATIONAL_YOUTH` 日誌、入庫筆數、決賽到場標示及排除理由。**在真實網站抓取前，無法保證新增多少筆。**
