## 資料保護與入庫門檻

1. 清單頁與詳情頁皆需屬於白名單的官方 `https://n058.ncut.edu.tw`，網址不可跳轉至其他網站；只抓公開競賽公告，限額抓取，絕不抓取帳密頁或非公開 API。
2. 必須明示 **報名截止日、可參加的學生／青年對象，以及初賽線上作品／企劃書上傳證據**；只有線上報名、不見繳交證據的不能推薦。
3. 線上初賽、實體決賽者，保留 `finalAttendanceRequired`、`finalLocation`（只從公告明文取得）；彰化、南投的實體決賽繼續依使用者偏好排除。
4. 欄位 `dateKind=application_deadline`，顯示「徵件截止」而非活動舉辦日期；正式使用者須自行核對主辦方最新簡章，且校方轉知不保證個人資格。
5. 任一**必要頁面抓取／資料結構失敗**，這個新增來源報告不健康、結果不覆蓋該來源舊資料；不得讓此來源失敗連累東海、台中、獎學金或已存在的8個來源。
6. 不修改既有正式資料庫，也不導入測試用假活動。活動仍需通過既有 `apply_fit_to_result`、去重、封存、官方 `AutoFetch` 正式程序，才可能入庫。

## 驗收流程

1. 安裝腳本建立獨立 branch，`python -m unittest discover -s tests/autofetch`、`bash scripts/verify.sh` 與 `git diff --check` 全部通過後建立 GitHub PR。
2. GitHub PR Safety Check + 真實瀏覽器測試都成功後才合併。
3. 合併後執行正式 `autofetch.yml`，檢查 `NCUT_COMPETITIONS`、`SOURCE_SUMMARY` 與 `data/activities.json.meta.officialCompetition*`，以及最新獎學金和舊活動完整性。
4. **此次本地19項來源合成離線測試與3項補丁安全測試成功 ≠ GitHub 正式抓取成功，也 ≠ 保證新增活動數**。如來源當天網站異常，應誠實顯示異常、不虛報。

此版只新增1個啟用來源：原14個登記來源 → 15個，原8個啟用來源 → 9個。停用的彰化、南投、臺大及政大實體專用來源不啟用。
