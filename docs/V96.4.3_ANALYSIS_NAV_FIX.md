# V96.4.3 分析口徑與手機導覽修正

## 1. 分析口徑
- 「本週執行安排」：只統計 executionPlans 中本週、未取消安排的預計分鐘；沒有安排時顯示 0。
- 「本週整體投入」：統計目標系統當週有效 Level 4 週投入目標與實際投入，不再使用 executionPlans 的分鐘數。
- 「計畫 × 實際執行」：獨立統計提前安排、安排實際執行、取消安排與歷史實際紀錄。
- 當沒有有效執行安排時，計畫實際執行率與時間達成率顯示「—」，避免把 0/0 誤表示成 0%。
- 已取消安排不列入目前有效計畫；其歷史實際紀錄仍保留。

## 2. 手機導覽
- 向上滑動（手指向上）時隱藏底部導覽。
- 向下滑動（手指向下）時顯示底部導覽。
- 同時保留 scroll 事件作為 WebView/瀏覽器 fallback。
- 到頁面頂端時強制顯示。
- 隱藏時完全移出畫布，不以半透明殘留方式佔據視覺。
