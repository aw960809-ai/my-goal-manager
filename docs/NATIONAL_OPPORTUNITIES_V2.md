# 全國活動雷達：可遠端參與的官方徵件與競賽（V2）

本次只增加兩個全國官方來源：青年第一讚（競賽／活動分類）與青年署最新消息及青年計畫消息。
現有 12 個來源不移除，彰化、南投及臺大／政大實體講座專屬來源繼續停用。

## 進入推薦的必要證據

- 官方 HTTPS 清單＋同網域官方詳情，來源及固定 ID 可核對。
- 徵件必須有可核對的未來截止日期與線上交件方式；線上講座要有線上舉辦證據，線上報名實體講座不算。
- 排除兒童親子、已截止、已錄取名單、特定身分限制、必須實體到場的競賽決賽與明確前置資格不足的機會。
- 申請截止日顯示「徵件截止」，不是誤說成活動舉辦日；前端亦會標示。
- 一個來源任何抓取或必要結構失敗時，不刪除該來源舊資料；不影響其他來源。
- 只使用官方新聞或官方青年資源平台，不將過期活動、貸款、網站入口或人工假資料湊數。
- 合併前僅為程式碼＋合成離線測試；實際收錄數需要正式 AutoFetch 再驗證。

- https://www.yda.gov.tw/docList.aspx?pid=53&uid=59
