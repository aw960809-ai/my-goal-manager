# 活動雷達四格篩選整合（Phase 4.1）

## 目的
把原有的四張同心圈層說明卡升級為可操作篩選按鈕，移除重複的可見下拉選單，但保留原生 `#activityScope` 與全部原有分類規則。

- 每次只選一個圈層：東海校內、台中、中部、全國。
- 再按一次同圈層即回到「全部圈層」。
- 類型、適配度、子任務篩選仍然可與圈層交叉套用。
- 選取按鈕具有 `aria-pressed`、明確標籤、鍵盤操作及可見焦點。
- `activityResetFilters` 改動原生選單時，原有活動摘要重繪會同步四格狀態。
- JS 初始化失敗時不隱藏舊有圈層下拉選單，仍可使用舊操作。

## 資料與風險界線
本次只修改 `js/navigation.js` (呈現及 UI 導覽橋接)、`css/design-system.css`（已存在的設計層）、一份 UI 測試、此說明檔。原始 `index.html`、`js/activity.js`、`js/domain/radar-policy.js`、個人資料、統計與 PWA 設定都不改變。此套件必須先經完整 `scripts/verify.sh` 與 GitHub PR 測試，才可依原先白名單自動合併。

## 驗收
手機活動雷達：原有四個下拉選單縮減成「類型、適配度、子任務」；四張圈層卡點選後高亮，活動列表與統計同步變更。點第二圈切換第二圈，再點一次取消；重設篩選後四格恢復未選。其他功能、活動審查及跨頁導覽不受影響。
