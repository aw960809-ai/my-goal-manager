## 活動收錄驗證

- 僅可在校方官方網站列表與詳情頁核對的來源；強制 HTTPS 及來源網域白名單。
- 需有未來日期、活動地點、校方明示免報名／自由入場；僅有「開放報名」而缺乏資格或期限證據，不自動推薦。
- 不把公告日期或活動結束日期誤判為參與日期；一篇公告的兩場次分開收錄。
- 文化部原始資料若只是「英文」字樣，不能直接視為多益、日檢或成人語言訓練。
- 已公開的兒童繪本類誤推薦項目，即使舊版仍留在手機本機快取，也不列入推薦；文化部來源健康驗證後將正式目錄紀錄轉入歷程封存，仍可稽核。
- 法律、辯論、公共政策、專業語言等具有明確學習關聯的活動依既有 fitScore 評分，不重新定義所有個人目標。

## 正式驗收後才確認的項目

PR 和 GitHub Actions 離線測試不是資料抓取成功的證明。正式更新後，檢查 settings：
`來源健康`、`全國法律學術活動`、`低相關活動已封存` 和 `全國活動（官方資料）`。
使用 `data/activities.json` 的 meta 欄位與 `data/activity-archive.json` 確認實際筆數。
