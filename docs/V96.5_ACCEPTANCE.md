# V96.5 最終工程整理版驗收

## 原則
本版不新增工作模組，不改變 V92 資料主鍵與 schema 5；以穩定、可逆、模組邊界、手機相容與資料保護為主要目標。

## 已完成
- 底部導覽與手機手勢從 `app.js` 抽離至 `js/navigation.js`。
- 導覽採事件委派，降低導覽與各模組 UI 的耦合。
- 保留 Android Chrome／content:// 預覽的 pointer、touch、scroll 三層回退。
- CSS 介面檔統一命名為 `css/app-ui.css`，避免版本號樣式檔名持續堆疊。
- 手機 edge-to-edge、Safe Area、行事曆與底部導覽既有規則保留。
- 本機資料仍使用既有同步 FNV-1a 完整性機制以維持相容。
- 匯出備份新增 Web Crypto SHA-256 完整性摘要；匯入時驗證。
- 損壞備份仍拒絕匯入；舊版 FNV 備份維持相容。
- GitHub Pages Service Worker cache 升版至 V96.5，加入 navigation.js。
- index.html 增加非破壞性的 `base-uri`／`object-src` CSP 基礎限制。
- 系統診斷新增 SHA-256 備份完整性檢查。
