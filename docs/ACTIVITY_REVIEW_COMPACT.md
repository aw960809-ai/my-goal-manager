# 活動雷達待複核精簡清單（第四階段第三批）

## 範圍

只修改 `js/activity.js` 的待複核資訊呈現，並將舊的 JavaScript 動態注入樣式移到既有 `css/design-system.css` 設計層。新增一份使用合成資料的 UI 回歸測試。

## 行為

- 來源待複核預設收合，保留原有 `<details>` 操作與說明。
- 展開後先顯示五筆；每按一次再顯示最多五筆，直到顯示所有項目。
- 每筆列出活動名稱、最後確認日期、來源缺失次數、來源名稱與官方來源連結。
- 詳細的複核原因可單筆展開，避免相同句子重複佔據手機畫面。
- 本輪來源待複核、本機額外保留與總計持續採用先前的來源統計邏輯。
- 篩選、換頁或重新渲染時，保留目前的清單展開狀態與已載入筆數。
- 來源連結在新分頁開啟；文字經過 HTML escape 處理。

## 資料安全

不修改 `db.activities`、資料來源抓取、資料合併、`RadarPolicy`、資料儲存、目標系統、歷史紀錄、PWA 設定。被標示為待複核的來源仍不列入推薦。所有 22 筆（或使用者實際筆數）原資料仍保留在瀏覽器中。

## 後續另行處理

1. 設定頁統整來源審查與更詳細的維護入口。
2. 主要活動推薦卡片精簡。
3. 苗栗、彰化、南投、雲林官方來源擴充（涉及後端資料來源與資格判斷，必須另外審查）。

本批包含受保護檔案 `js/activity.js`，提交人工審查 PR，不啟用 `safe-auto-merge`。
